0xc00d36c4: is it the codec, or is the file broken?

The Windows Movies & TV app (and the newer Media Player) shows the same message for two unrelated problems: “This file isn't playable. That might be because the file type is unsupported, the file extension is incorrect, or the file is corrupt. 0xc00d36c4”. Most of the time it's the first one. Sometimes it's the last one, and the fix is completely different.

Applies to MP4 and MOV files from Sony, DJI, GoPro, iPhone and most other cameras.

The 30-second test

Open another clip from the same camera, shot the same day with the same settings.

  • That one won't play either: it's the codec, not the file. Newer cameras and phones record HEVC (H.265), which Windows can't play out of the box. Nothing is broken.
  • The other clips play and only this one fails: the file is the problem, and almost always it's a recording that was cut off before the camera finished it.

If it's the codec

  • Install “HEVC Video Extensions” from the Microsoft Store, and the built-in apps will play the files.
  • Or open the file in VLC, which plays HEVC without installing anything.

If it's the file

A recording that stopped early has all its picture and sound but no index, the map a player needs to find the frames. Renaming won't add it, and converters can't read a file they can't open. What works is rebuilding the index from a healthy clip:

  1. Don't format the card, don't keep shooting on it. Copy the file to your computer and work on the copy.
  2. A sample clip. A healthy recording from the same camera at exactly the same settings: same resolution, same frame rate, same recording quality. Length doesn't matter. If you don't have one, put a card in, lens cap on, record 30 seconds.
  3. untrunc. A free tool that rebuilds the index from your sample clip (download it here, Windows, with a simple interface). Pick the sample clip, pick the broken file, run it. It's the same method the paid tools use. Sometimes it takes a second run.
  4. Then check the whole file. The duration should match what you shot. Scrub to five or six points across it, especially near the end, and watch a few seconds at each. Lips should still match sound. If anything's off, the answer is a better-matched sample clip and another pass, not a different program.

On Sony cameras the broken file may end in .RSV instead of .MP4; that's its own page.

Short answers

  • Does 0xc00d36c4 mean my video is corrupt? Usually not. Most of the time Windows just can't play the codec, typically HEVC. Test another clip from the same camera: if that fails too, install the HEVC extension or use VLC.
  • Will converting the file fix it? Only if some program can open it. If VLC can't play it either, the file has no index, and a converter can't read it. Rebuild the index from a sample clip first.
  • VLC plays it but Windows doesn't. Then the file is fine. Install the HEVC Video Extensions from the Microsoft Store, or keep using VLC.
