A Sony .RSV file: what it is and how to open it

There's a file on the card that ends in .RSV instead of .MP4, and nothing will open it. That's Sony's way of saying the recording never got finished: the camera shut off, the battery died, or the card came out while it was still writing. The footage is almost always still inside.

Applies to the FX3, FX30, FX6, A7S III, A7 IV, ZV-E1 and other Sony bodies that record XAVC.

What an .RSV file actually is

While a Sony camera records, it writes the picture and sound to the card straight away, under a temporary name ending in .RSV. The one thing it saves for the very end, when you press stop, is the index: the map that tells a player where every frame sits. At that moment the file becomes a normal .MP4. If the power goes first, the file keeps its temporary name and has no map.

That's why renaming it to .MP4 usually does nothing. The extension changes, the map is still missing, and a player still can't find the first frame.

What the camera will say

The next time you switch the camera on with that card, it may show “Image Database File error. Recover?” Choose recover and let it finish. According to Sony's own help guide this repairs the camera's index of the card and deletes nothing. Don't expect it to fix the recording, though: it fixes the card's catalogue, not the file.

Before you do anything

  • Don't format the card.
  • Don't keep shooting on it. Whatever gets overwritten is gone.
  • Copy the .RSV file to your computer and work on the copy.
  • While you're at it, copy a healthy clip from the same card too. You'll need it in a minute.

How to rebuild it

  1. A sample clip. A healthy recording from the same camera at exactly the same settings: same resolution, same frame rate, same recording quality. Length doesn't matter. If you don't have one, put a card in, lens cap on, record 30 seconds.
  2. untrunc. A free tool that rebuilds the index from your sample clip (download it here, Windows, with a simple interface). In its settings, tick the option for .RSV files. Pick the sample clip, pick the broken file, run it. It's the same method the paid tools use. Sometimes it takes a second run.
  3. Then check the whole file. The duration should match what you shot. Scrub to five or six points across it, especially near the end, and watch a few seconds at each. Lips should still match sound. If anything's off, the answer is a better-matched sample clip and another pass, not a different program.

Short answers

  • Can I just rename .RSV to .MP4? You can, but it usually changes nothing. The file is missing its index, and a new extension doesn't add one.
  • Will the camera repair the .RSV file? No. “Image Database File error. Recover?” repairs the camera's catalogue of the card so it can keep recording. Sony's help guide notes it deletes nothing, but it doesn't rebuild the recording.
  • Does the length of the recording matter? Not for whether it can be rebuilt. A two-hour recording rebuilds the same way as a two-minute one; it just takes longer and needs more disk space.
