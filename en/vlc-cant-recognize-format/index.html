VLC “can't recognize the input's format”: what it means for a camera file

The full message is “VLC can't recognize the input's format: The format of 'file:///…' cannot be detected. Have a look at the log for details.” VLC plays almost anything, so when it gives up on a file from a camera, the problem isn't a codec. The file has no index.

In VLC's log the line underneath is usually “moov atom not found”.

Why VLC fails on this file

An MP4 or MOV carries a small index, the map that says how long the file is and where each frame sits. Cameras write it last, at the moment the recording ends cleanly. If the camera shut down, the battery died or the card was pulled first, the map was never written. VLC opens the file, finds no map, and can't even tell what it's looking at. Renaming the file or changing the extension doesn't add the map.

Check the size before anything else

The other way a file ends up without an index is a transfer that stopped halfway: a download, WeTransfer, Drive or a copy that didn't finish. Compare the size with the original on the card or the sender's copy. If it's smaller, no repair will help; get the file again. If it's the full size, the footage is inside and the index can be rebuilt.

How to rebuild the index

  1. Don't format the card, don't keep shooting on it. Copy the file to your computer and work on the copy.
  2. A sample clip. A healthy recording from the same camera at exactly the same settings: same resolution, same frame rate, same recording quality. Length doesn't matter. If you don't have one, put a card in, lens cap on, record 30 seconds.
  3. untrunc. A free tool that rebuilds the index from your sample clip (download it here, Windows, with a simple interface). Pick the sample clip, pick the broken file, run it. It's the same method the paid tools use. Sometimes it takes a second run.
  4. Then check the whole file. The duration should match what you shot. Scrub to five or six points across it, especially near the end, and watch a few seconds at each. Lips should still match sound. If anything's off, the answer is a better-matched sample clip and another pass, not a different program.

Short answers

  • Is this a codec problem? No. VLC ships with every codec a camera uses. When VLC can't recognize a camera file, the file's index is missing.
  • Can VLC repair the file? No. VLC has a repair option for AVI files only. For MP4 and MOV you need a tool that rebuilds the index from a sample clip, such as untrunc.
  • The file plays for a bit and then stops. Different problem: the file has an index but part of the data is missing, usually from an interrupted transfer. Get the file again from the source.
