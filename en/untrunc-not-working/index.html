The full guide: what happened, what not to do, the three cases

untrunc didn't work? What to check before giving up

You downloaded the program, picked a sample clip, ran it, and got: a file that won't open, a video that jumps, sound that drifts, or a two-minute file instead of an hour. It happens a lot, and it's almost never the program failing. There's a short list of things to check, in order, and only after it can you say the file is really lost.

This guide is for anyone who tried to rebuild a file with untrunc, or with the paid programs that work the same way: Sony RSV, DJI, GoPro, MP4 and MOV.

In short

  • What happened: the program builds the broken file a new map from the sample clip. If the sample differs from the file in one small detail (frame rate, compression type, audio setting), the map comes out skewed, and the result jumps or is missing pieces.
  • What not to do right now: don't install yet another program, don't try to “convert” the result, and don't delete the original file or your attempts.
  • What to do: go through the five checks below, in order. Most of the time the fix is a different sample clip.
  • Don't want to deal with it? Send me the file. The check is free, and if I couldn't recover it, you get your money back. How to send it.

What did you get? That tells you what to check

  • The video jumps, shows blocks, or the sound drifts toward the end: the sample clip doesn't match closely enough. Checks 2 and 3.
  • No sound at all: the audio setting on the sample clip is different (an external mic versus the built-in one, say). Check 3.
  • The output is far shorter than what you shot: either the footage really isn't there (check 1), or the program stopped partway (check 4).
  • The program crashed, or nothing came out: checks 1 and 5.
  • The file opens and looks great: check all of it before trusting it, the end included. The problems hide in the middle.

Five checks, in order

  1. Is the file complete? Compare its size with the original on the card. A file that came by transfer (WeTransfer, Drive, a download) and stopped halfway looks fine and is empty inside, and no program builds that. How you know: exactly the same size as on the card. If you have no access to the card, send it over, and the check whether the footage is inside is free.
  2. Does the sample clip match exactly? Same camera, same resolution, same frames per second, same compression type (H.264 or HEVC), same recording quality. Safest: the clip shot right before or after the broken one, with no setting changed. On DJI and GoPro, make sure the camera didn't switch between H.264 and HEVC during the day.
  3. Does the sound match too? Same audio setting: built-in or external mic, same number of channels, same quality. A clip shot with a different mic can give a perfect video with no sound.
  4. Was it run on a copy, on the computer's own drive? Work on a copy on the computer, not straight off the card and not from a slow external drive. A big file takes time: for an hour of footage the program can work for long minutes without showing progress. Wait.
  5. Sony: is the RSV option ticked? The program has a dedicated option for Sony .RSV files (in the windowed version: the Settings tab), and without it the file isn't recognised at all. And if nothing comes out for any file, download the current version again.

When none of that helped

Try another sample clip, and another. It sounds odd, but it's the fix in most cases: one clip isn't similar enough, another is. If after three different clips the result still jumps, or the file won't open at all, that's the time to send it: the check is free, and the answer says whether the footage exists and whether it's worth going on.

Short answers

  • Would a paid program do it better? No. They all work the same way: build a new map from a sample clip. If untrunc failed because of a mismatched clip, they fail for the same reason.
  • The video opens, but the sound only drifts at the end. Good enough? For editing, no. Sound drifting at the end most likely means the map is slightly off along the whole file. A closer sample clip fixes that, not re-exporting.
  • How do you know the footage is even in the file? A cut-off video file looks its normal size from the outside, but inside it can be empty: the part the camera or the transfer never got to write is like blank pages at the end of a notebook. In the free check I open the file and see how much of it really holds picture and sound and how much is blank, and that takes a minute. If most of the file is blank, there is nothing to recover, and no program will help.
