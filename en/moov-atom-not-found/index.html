“moov atom not found”: what it means and what to do

You'll see it from ffmpeg, in VLC's log, in HandBrake or in an editing app when you try to open an MP4 or MOV that has no index. It's common with DJI (Osmo, Mavic, Pocket), GoPro, dashcams and phones, and it always means one of two things.

The full line usually reads: [mov,mp4,m4a,3gp,3g2,mj2] moov atom not found.

What the moov atom is

Every MP4 and MOV has a small block called moov: the map that tells a player how long the file is and where every frame sits. Cameras write it last, when the recording ends cleanly. No moov, no map, and the player refuses the file even though the picture and sound may be sitting right there.

Two very different reasons you see it

Same message, opposite situations, and the first thing to do is find out which one you have.

  • The recording was cut off. The camera shut down, the battery died, the card was pulled, the app crashed. The file is full size and the data is inside; it just never got its map. This is repairable.
  • The transfer stopped halfway. A download, WeTransfer, Drive sync or copy that didn't finish. The file looks like a video but the end of it is empty, and no repair tool can rebuild data that never arrived. The fix is to get the file again from wherever it came from.

How to tell: compare the size with the original on the card or the sender's copy. A file that's much smaller than it should be, or that stops at a suspiciously round number of megabytes, came through a broken transfer. I once got one cut at exactly 1050 MB that was 88 percent empty inside.

What doesn't work

  • Renaming the file or changing the extension.
  • ffmpeg with -c copy or -movflags faststart. Both need an existing moov to read the file at all; they can move an index, not invent one.
  • Converters and players that “repair on the fly”. Same problem: they can't read what they can't open.

What works

  1. Don't format the card, don't keep shooting on it. Copy the file to your computer and work on the copy.
  2. A sample clip. A healthy recording from the same camera at exactly the same settings: same resolution, same frame rate, same recording quality, and the same codec (H.264 or HEVC; DJI and GoPro can switch between the two). Length doesn't matter. If you don't have one, put a card in, lens cap on, record 30 seconds.
  3. untrunc. A free tool that rebuilds the index from your sample clip (download it here, Windows, with a simple interface). It handles DJI, GoPro and most other brands. Pick the sample clip, pick the broken file, run it. It's the same method the paid tools use. Sometimes it takes a second run.
  4. Then check the whole file. The duration should match what you shot. Scrub to five or six points across it, especially near the end, and watch a few seconds at each. Lips should still match sound. If anything's off, the answer is a better-matched sample clip and another pass, not a different program.

Short answers

  • Can ffmpeg fix “moov atom not found”? Not when the moov was never written. ffmpeg needs the index to read the file at all, and -movflags faststart only moves an index that already exists. You need a tool that rebuilds the index from a sample clip.
  • The file is the right size but still won't open. Then the recording was interrupted and the footage is there. Rebuild the index from a sample clip from the same camera at the same settings.
  • The file came from a download or WeTransfer. Check its size against the original first. If it's smaller, the transfer failed and no repair will help; ask for the file again.
